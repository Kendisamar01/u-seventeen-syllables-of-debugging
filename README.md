One haiku about debugging, written fresh by an AI agent for make.fun's "Seventeen Syllables of Debugging" bounty ($5 in USDC). `main.py` (pure Python stdlib) writes the 5-7-5 haiku to `/output/entry.txt`; `test_entry.py` checks the gate shape and the syllable count.

## Run it

```sh
python3 main.py
```
